============================================================
  비트코인 선물 자동매매 — 사용설명서
============================================================

■ 설치할 것 없습니다
  HedgedMartingaleBot.exe 를 더블클릭하면 바로 실행됩니다.

  ※ 백신이 경고를 띄울 수 있습니다.
    서명되지 않은 프로그램이라 생기는 오탐지이며, '허용'을 눌러주세요.

------------------------------------------------------------
■ 시작하기

  1. 거래소 선택 (Gate.io / Binance / Bybit / OKX / Bitget)

  2. "📖 API Key 발급방법" 버튼을 눌러 안내대로 키를 발급받으세요.
     · 선물(Futures) 거래 권한을 반드시 켜야 합니다.
     · 출금 권한은 절대 켜지 마세요.
     · OKX, Bitget은 Passphrase도 함께 입력해야 합니다.
     · 거래소가 IP 제한을 요구하면, 이 PC의 IP를 등록하세요.

  3. API Key / Secret Key 입력

  4. 설정할 것은 없습니다
     매매 설정은 아래 값으로 고정되어 있어 따로 입력하지 않습니다.
       · 레버리지        25배
       · 1회 진입 크기   잔고의 3%
       · 증거금 모드     교차(Cross) — 시작할 때 자동으로 맞춥니다
       · 야간 정지       밤 21시 ~ 새벽 1시 (한국 시간)
     "⚠️ 주의사항" 버튼을 꼭 읽어보세요.

  5. "▶ 자동매매 시작" 클릭

  6. 멈출 때는 "■ 정지"

------------------------------------------------------------
■ 시작 전 확인

  □ 선물 지갑에 USDT가 들어 있는지
  □ 기존에 열려 있는 포지션이나 미체결 주문이 없는지
     (있으면 레버리지·증거금 모드 설정이 거부될 수 있습니다)
  □ 처음에는 반드시 소액으로 하루 이상 돌려보세요

------------------------------------------------------------
■ 화면 보는 법

  상태줄        현재 보유 중인 롱/숏 포지션
  ⏱ 시세 ...    30초마다 갱신되는 현재가와 상태
                (이 줄이 계속 바뀌면 정상 작동 중입니다)
  ▶ 진입        새로 매수/매도한 금액과 가격
  ■ 청산        정리한 포지션의 수익 또는 손실
  📊 매매 기록   "매매 기록 보기" 버튼으로 전체 내역 확인

  시작할 때 아래 줄이 나오는지 확인하세요.
    증거금 모드: 교차(Cross) / 레버리지 25배 / 진입금액 3%
    계좌 잔고: 1,234.56 USDT

------------------------------------------------------------
■ 밤 21시 ~ 새벽 1시에는 새 매매를 하지 않습니다

  이 시간대는 시세가 크게 흔들려 손실이 나기 쉽습니다.
  그래서 새로 들어가지 않고, 가지고 있는 것만 관리합니다.
  수익 구간이 오면 그때는 정리하고 나옵니다.

  시작할 때와 끝날 때 아래 안내가 로그에 남습니다.
    🌙 야간 정지 시간대(21:00~01:00)에 들어갔습니다. 새 매매를 하지 않습니다.
    ☀ 야간 정지 시간대(21:00~01:00)가 끝났습니다. 매매를 재개합니다.

  이 시간 동안 ⏱ 줄 끝에 🌙 표시가 붙습니다. 멈춘 게 아니라 정상입니다.

  ※ 서버가 해외에 있어도 한국 시간을 기준으로 판단합니다.

------------------------------------------------------------
■ 프로그램을 껐다 켜면

  진행 중이던 매매를 그대로 이어서 합니다.
  거래소에 열려 있는 실제 포지션을 확인해서 맞춥니다.

  ※ 꺼져 있는 동안에는 아무 매매도 하지 않습니다.
     포지션을 들고 있을 때 오래 꺼두지 마세요.

------------------------------------------------------------
■ 자주 묻는 문제

  Q. "계좌를 조회하지 못했습니다" 가 뜹니다
  A. 화면에 나오는 안내를 그대로 따라주세요. 원인별로 알려줍니다.
     · API Key/Secret 오타
     · 선물 거래 권한 미설정
     · 이 PC의 IP가 거래소 허용 목록에 없음

  Q. "주문을 처리하지 못했습니다" 가 반복됩니다
  A. 잔고가 거래소 최소 주문 금액에 못 미치거나 증거금이 부족합니다.
     선물 지갑에 USDT를 더 넣어주세요.

  Q. 시세 줄(⏱)이 멈춰 있습니다
  A. 인터넷 연결이 끊겼을 수 있습니다. 잠시 후 자동으로 재시도합니다.

  Q. "증거금 모드를 바꾸지 못했습니다" 가 뜹니다
  A. 포지션이나 미체결 주문이 있으면 거래소가 변경을 거부합니다.
     포지션이 정리되면 프로그램이 자동으로 다시 시도합니다.

  Q. "격리(Isolated) 마진에서는 시작하지 않았습니다" 가 뜹니다
  A. 격리 모드에서는 손실이 통제되지 않아 일부러 시작을 막습니다.
     거래소에서 해당 종목을 교차(Cross)로 바꿔주세요.
     포지션과 미체결 주문을 모두 정리한 뒤에 바꿀 수 있습니다.

------------------------------------------------------------
■ 반드시 알아두실 것

  이 프로그램은 손실이 날 수 있습니다.
  잃어도 생활에 지장이 없는 금액으로만 사용하세요.

  이 프로그램은 레버리지 25배로 거래합니다. 시세가 반대로 가면
  손실이 그만큼 빠르게 불어납니다. 반드시 교차(Cross) 모드에서만
  사용하시고, 처음에는 소액으로 충분히 지켜본 뒤 금액을 늘리세요.

  프로그램 안의 "⚠️ 주의사항" 버튼에 자세한 내용이 있습니다.
  시작하기 전에 꼭 읽어주세요.
