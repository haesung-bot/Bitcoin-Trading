============================================================
  EXE 만드는 방법 (운영자용)
============================================================

윈도우 PC에서 "배포용_빌드.bat" 를 더블클릭하세요. 끝입니다.

  · 파이썬만 미리 설치되어 있으면 됩니다.
    https://www.python.org/downloads/
    설치할 때 "Add Python to PATH" 를 반드시 체크하세요.

  · 나머지(패키지 설치, 예전 빌드 정리, 빌드)는 자동입니다.
  · 5~10분 걸립니다.
  · 완료되면 dist\HedgedMartingaleBot.exe 가 생깁니다.

------------------------------------------------------------
직접 명령어로 하려면

  pip install pyinstaller ccxt requests certifi

  python -m PyInstaller --onefile --noconsole ^
      --name "HedgedMartingaleBot" ^
      --collect-all ccxt --collect-all certifi ^
      hedged_martingale_bot_gui.py

  --collect-all ccxt    : 빼면 실행 시 ModuleNotFoundError 발생
  --collect-all certifi : 빼면 TLS 인증서 오류로 거래소 연결 전부 실패

------------------------------------------------------------
⚠️ 코드를 고쳤는데 반영이 안 될 때

  build 폴더, dist 폴더, .spec 파일을 지우고 다시 빌드하세요.
  (배포용_빌드.bat 는 이걸 자동으로 합니다)

  실행 후 로그 첫 줄의 버전 번호로 최신 여부를 확인할 수 있습니다.
  이 패키지는 v1.3.1 입니다.

------------------------------------------------------------
배포 방법 (텔레그램 봇 연동)

  1. dist\HedgedMartingaleBot.exe 와 사용설명서.txt 를 압축
     → 파일 이름은 반드시  HedgedMartingaleBot.zip

  2. GitHub → Releases → "Draft a new release"
     - 태그: v1.3.1
     - 파일 첨부: HedgedMartingaleBot.zip
     - Publish release

  3. 끝. 텔레그램 봇은 항상 최신 릴리스를 내려줍니다.
     (봇 코드를 고칠 필요가 없습니다)

  ※ 압축파일 이름을 HedgedMartingaleBot.zip 이 아닌 다른 걸로 올리면
     다운로드 링크가 깨집니다. 이름을 꼭 지켜주세요.

------------------------------------------------------------
배포용에 들어있지 않은 것 (개인용 전용)

  · 텔레그램 알림
  · 익절/물타기/손절 % 직접 조정
  · 최대 물타기 단계 조정
  · 3차 헷지, 추세 필터
  · 상세 로그

  배포용은 거래소·API 키·레버리지·포지션 크기만 노출되며,
  매매 로그에 진입 차수나 전략 용어가 나오지 않습니다.
