============================================================
  배포용 EXE 만드는 법  (HedgedMartingaleBot.exe)
============================================================

윈도우 PC에서 아래 순서대로 따라 하시면 됩니다.
전부 복사해서 붙여넣기만 하면 되고, 5~10분 걸립니다.


------------------------------------------------------------
■ 준비물

  1) 윈도우 PC (맥에서는 윈도우용 EXE를 만들 수 없습니다)

  2) 파이썬 3.10 이상
     https://www.python.org/downloads/

     ※ 설치 화면 맨 아래 "Add Python to PATH" 를 반드시 체크하세요.
        이걸 빼먹으면 아래 명령어가 하나도 안 먹습니다.

  3) 아래 두 파일을 한 폴더에 넣어주세요 (예: C:\bot)
       · hedged_martingale_bot.py       (엔진)
       · hedged_martingale_bot_gui.py   (화면)

     ※ 두 파일은 반드시 같은 폴더에, 같은 버전으로 있어야 합니다.
        하나만 새로 덮어쓰면 프로그램이 실행될 때 오류를 띄웁니다.


------------------------------------------------------------
■ 1단계 — 그 폴더에서 명령창 열기

  파일 탐색기로 파일을 넣어둔 폴더(C:\bot)를 엽니다.
  주소창(위쪽에 C:\bot 이라고 적힌 칸)을 클릭해서 글자를 지우고
  cmd 라고 친 뒤 Enter.

  검은 명령창이 뜨고 맨 앞에 C:\bot> 이라고 나오면 성공입니다.

  (또는 폴더 안 빈 곳에서 Shift + 마우스 오른쪽 클릭
   → "여기에 PowerShell 창 열기" 를 눌러도 됩니다)


------------------------------------------------------------
■ 2단계 — 파이썬이 깔렸는지 확인

  아래 한 줄을 복사해서 붙여넣고 Enter.

python --version

  → Python 3.12.x 처럼 버전이 나오면 정상입니다.

  → "'python'은(는) 내부 또는 외부 명령... 이 아닙니다" 가 나오면
     파이썬이 안 깔렸거나 PATH 체크를 빼먹은 겁니다.
     파이썬을 지우고 "Add Python to PATH" 를 체크해서 다시 설치하세요.


------------------------------------------------------------
■ 3단계 — 필요한 프로그램 설치 (처음 한 번만)

  아래 한 줄을 붙여넣고 Enter. 몇 분 걸립니다.

python -m pip install --upgrade pyinstaller ccxt requests certifi

  → 마지막에 Successfully installed ... 이 나오면 완료입니다.

  ※ 회사망이나 공용 와이파이에서 실패하면 개인 인터넷에서 해보세요.


------------------------------------------------------------
■ 4단계 — 예전 빌드 찌꺼기 지우기 (중요)

  이걸 안 지우면 파일을 새로 바꿔도 예전 내용 그대로 EXE가 나옵니다.
  "분명히 수정했는데 안 바뀐다" 는 대부분 이것 때문입니다.

  아래 세 줄을 한 줄씩 붙여넣고 Enter.

rmdir /s /q build
rmdir /s /q dist
del /q HedgedMartingaleBot.spec

  → "지정된 파일을 찾을 수 없습니다" 가 나와도 괜찮습니다.
     원래 없었다는 뜻이니 그냥 다음으로 넘어가세요.


------------------------------------------------------------
■ 5단계 — EXE 만들기

  아래 한 줄을 통째로 복사해서 붙여넣고 Enter.
  (줄이 길어 보여도 한 줄입니다. 중간에 끊지 마세요)

python -m PyInstaller --onefile --noconsole --name HedgedMartingaleBot --collect-all ccxt --collect-all certifi hedged_martingale_bot_gui.py

  5~10분 걸립니다. 글자가 계속 올라가는 동안 창을 닫지 마세요.

  맨 마지막에 이런 줄이 나오면 성공입니다.
    Building EXE from EXE-00.toc completed successfully.


------------------------------------------------------------
■ 6단계 — 결과 확인

  dist 폴더 안에 HedgedMartingaleBot.exe 가 생겼습니다.

  이 파일 하나만 배포하면 됩니다.
  받는 사람은 파이썬을 깔 필요가 없습니다.

  배포 전에 직접 확인할 것
    1) HedgedMartingaleBot.exe 를 더블클릭해서 창이 뜨는지
    2) 로그 첫 줄의 버전 번호가 최신인지 (v1.4.3)
    3) 소액으로 하루 돌려보고 로그가 정상으로 찍히는지


------------------------------------------------------------
■ 안 될 때

  Q. 5단계에서 "No module named PyInstaller" 가 나옵니다
  A. 3단계를 안 했거나 실패한 겁니다. 3단계를 다시 하세요.

  Q. "hedged_martingale_bot_gui.py: No such file" 이 나옵니다
  A. 명령창이 지금 있는 위치에 그 파일이 없습니다.
     명령창 맨 앞 경로(C:\bot>)가 파일을 넣어둔 폴더가 맞는지 보세요.
     아래처럼 폴더를 직접 지정해도 됩니다.
       cd /d C:\bot

  Q. 빌드는 됐는데 EXE를 켜면 바로 꺼집니다
  A. 4단계(찌꺼기 삭제)를 건너뛴 경우가 많습니다.
     build, dist, HedgedMartingaleBot.spec 을 지우고 5단계를 다시 하세요.

  Q. 백신이 바이러스라고 잡습니다
  A. 서명되지 않은 EXE라서 생기는 오탐지입니다.
     백신 예외에 등록하시고, 받는 분들께도 미리 알려주세요.

  Q. EXE 파일이 너무 큽니다 (60MB 내외)
  A. 정상입니다. 파이썬과 거래소 라이브러리가 통째로 들어가 있습니다.


------------------------------------------------------------
■ 파일을 수정한 뒤 다시 만들 때

  4단계 → 5단계만 다시 하면 됩니다. (2, 3단계는 처음 한 번만)
  4단계를 꼭 먼저 하세요. 안 그러면 수정한 내용이 반영되지 않습니다.
