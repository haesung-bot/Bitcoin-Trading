# 🍳 냉장고 요리사

집에 있는 식재료를 입력하면, **그 재료로 지금 만들 수 있는 요리**를 찾아주는 앱입니다.

레시피 58종을 내장하고 있어 인터넷 연결이나 외부 API 없이 동작합니다.

---

## 실행 방법

```bash
cd recipe_app
pip install -r requirements.txt
python app.py
```

브라우저에서 <http://127.0.0.1:5000> 접속.

### 터미널에서 바로 쓰기

브라우저를 띄우기 귀찮을 때:

```bash
python cli.py 김치 계란 밥 대파
```

---

## 어떻게 추천하나요

재료를 넣으면 각 레시피의 **필수 재료**와 대조해 3단계로 분류합니다.

| 표시 | 의미 |
|------|------|
| 🟢 **바로 가능** | 필수 재료가 전부 있음 |
| 🟠 **1개만 더** | 딱 하나만 사면 됨 |
| ⚪ **조금 부족** | 2개 부족 |

정렬 순서는 `부족한 재료 적은 순 → 매칭률 높은 순 → 조리 시간 짧은 순`입니다.

### 이 앱이 챙겨주는 것들

**같은 재료를 다르게 써도 인식합니다.**
"달걀 / 계란 / 계란 2개", "삼겹살 / 돼지고기", "오뎅 / 어묵" 모두 같은 재료로 처리합니다.
분량("300g", "1공기")과 괄호 설명은 자동으로 떼어냅니다.

**기본 양념은 있는 걸로 칩니다.**
소금·간장·설탕·식용유·참기름 같은 건 집에 다 있으니 매번 입력하지 않아도 됩니다.
직접 체크를 끄면 양념까지 따져서 계산합니다.

**대체 재료를 알려줍니다.**
크림파스타에 생크림이 없어도 우유가 있으면 "생크림 → 우유로 대체 가능"이라고 표시합니다.

**장보기 목록을 뽑아줍니다.**
"이거 하나만 사면 만들 수 있는 요리가 3개 늘어나요" 식으로,
가장 많은 요리를 열어주는 재료부터 알려줍니다.

**필터링**
종류(밥/면/국찌개/반찬/간식/메인)와 조리 시간(15분·20분·30분 이내)으로 좁힐 수 있습니다.

## 파일 구성

```
recipe_app/
├── app.py              Flask 서버 (라우팅 + API)
├── matcher.py          매칭 엔진 (점수 계산·정렬·장보기 목록)
├── ingredients.py      재료명 정규화 (동의어·분량 제거·대체재료 표)
├── cli.py              터미널 버전
├── test_matcher.py     테스트 32개
├── data/recipes.json   레시피 58종
├── templates/index.html
└── static/{style.css, app.js}
```

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/ingredients` | 자동완성용 재료 목록 |
| POST | `/api/search` | 재료로 요리 검색 |
| GET | `/api/recipe/<id>` | 레시피 단건 조회 |

`POST /api/search` 요청 예시:

```json
{
  "ingredients": "김치, 밥, 달걀 2개",
  "use_staples": true,
  "max_missing": 2,
  "category": "밥/한그릇",
  "max_time": 20
}
```

응답에는 `results`(레시피별 상태·매칭률·부족 재료·대체 재료), `pantry`(정규화된 보유 재료), `shopping_list`가 담깁니다.

## 레시피 추가하기

`data/recipes.json`에 항목을 추가하면 됩니다. 코드 수정은 필요 없습니다.

```json
{
  "id": "고유-영문-id",
  "name": "요리 이름",
  "category": "반찬",
  "time_minutes": 15,
  "difficulty": "쉬움",
  "servings": "2인분",
  "tags": ["밑반찬"],
  "main":     [{"name": "계란", "amount": "3개"}],
  "optional": [{"name": "당근", "amount": "약간"}],
  "seasoning": ["소금 약간", "참기름 1작은술"],
  "steps": ["1단계", "2단계"],
  "tip": "한 줄 조언"
}
```

- `main`에 넣은 재료만 매칭 점수에 반영됩니다. 없어도 되는 건 `optional`로 보내세요.
- 새로운 재료의 다른 이름(별칭)을 인식시키려면 `ingredients.py`의 `ALIASES`에 추가합니다.
- 추가 후 `python test_matcher.py`를 돌리면 데이터 형식이 맞는지 검증됩니다.
